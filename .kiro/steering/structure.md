## Rules
- `src/core` must not import from `app`, `screens`, `audio`, or `platform`.
- Reducer files in `src/core` (`session.ts`, `session-intent.ts`, `session-end.ts`, `session-ended.ts`, `board.ts`) import shared types and helpers from `session-state.ts`, never from each other in a cycle.
- Anything that touches the DOM, timers (`setTimeout`, `setInterval`, `requestAnimationFrame`), browser events, or `Date.now()` lives outside `src/core` — in `src/app`, `src/screens`, `src/audio`, or `src/platform`.
- Screens never call browser APIs directly; they go through `src/platform`. Screens only build DOM from the state and view model they are given.
- Time is always passed in as a `now` parameter to core functions.
- Keep each file under about 200 lines; split when it grows.
- Never add `/.kiro` or any of its subfolders to `.gitignore` (submission requirement).
- New tests go next to their kind: pure-logic properties in `tests/property`, parser and edge cases in `tests/unit`.
